Sobre esta Aplicação

Esta secção detalha a arquitetura técnica, modelação de dados e tecnologias utilizadas na construção deste portfólio web.

1. Arquitetura MVT do Django

Desenho da Arquitetura:

A aplicação segue o padrão MVT (Model-View-Template) do Django. Os fluxos de informação funcionam da seguinte forma:

  • Model: Responsável por aceder e gerir a Base de Dados SQLite. Mapeia as tabelas usando classes Python (ORM).
  • View: Recebe o pedido HTTP, pede os dados ao Model, e passa-os para o Template.
  • Template: Ficheiro HTML dinâmico que gera a interface final para o utilizador.

class Projeto(models.Model):
    titulo = models.CharField(max_length=100)
    descricao = models.TextField()
    uc = models.ForeignKey(UnidadeCurricular, on_delete=models.CASCADE)
    tecnologias = models.ManyToManyField(Tecnologia, blank=True)

3. Tecnologias Utilizadas

Stack tecnológica utilizada no desenvolvimento deste projeto:

Django (Python)

Framework principal utilizado para o backend. Facilita a gestão da base de dados através do ORM e o controlo de rotas.

SQLite

Base de dados relacional por defeito no Django, utilizada para armazenar as UCs, projetos e competências.

HTML5 & CSS3

Utilizados para estruturar e estilizar as páginas do portfólio, garantindo um design responsivo e moderno.

Git & GitHub

Ferramentas essenciais para o controlo de versões do código e alojamento do repositório remoto.
